# 📊 売上・入金・繰越管理 ＆ 適格請求書（インボイス）発行シート

税理士さんや社内メンバーとGitHubプライベートリポジトリ（およびスプレッドシート/CSV）を介して安全・シンプルに共有できる、請求書ベースの売上・入金・売掛繰越管理Webアプリケーションです。

---

## ✨ 主な機能

1. **スプレッドシート形式のセル直接入力（元帳シート）**
   - 請求日・顧客・品目・10%対象・8%軽減対象・非課税・入金金額をセルで直接入力。
   - **期首（前月）繰越 ＋ 当月請求税込 − 当月入金額 ＝ 累計繰越残高（売掛残高）** を自動計算。
2. **同月 × 同一顧客の自動集計 ＆ 月まとめ合算請求書（締め請求書）発行**
   - 同じ月に同じ顧客へ複数の売上がある場合、自動で「同月×同一顧客」の小計行・月次締め集計を作成し、全明細を1枚にまとめた**月次合算請求書**をA4印刷・PDF出力可能。
3. **品目マスタ（10%標準 / 8%軽減税率 / 非課税の元データ）連動**
   - 品目マスタから選択するだけで10%・8%を自動判定し、軽減税率の「`※`」印や税率別消費税集計表を請求書へ自動印字。
4. **任意の決算月（期末単位）設定 ＆ 税理士共有用出力**
   - 1月〜12月決算まで自由に変更可能。ワンクリックでGoogleスプレッドシート貼付用コピーやUTF-8(BOM付) CSV出力が可能。
5. **☁ GitHub プライベートリポジトリ共有・同期機能**
   - リポジトリ内の `data.json` をクラウドデータベースとして利用し、ブラウザ上の **「☁ 最新を取得 (Pull)」「⬆ GitHubへ保存 (Push)」** ボタンだけで社員・税理士さんと最新データを共有。

## 🚀 GitHub（プライベートリポジトリ）での共有・運用手順

### ステップ1：GitHubに非公開（Private）リポジトリを作成してPushする

GitHub上で新規の **Private（非公開）リポジトリ**（例：`sales-ledger-sheet`）を作成し、このフォルダ内で以下のコマンドを実行してアップロードします。

```powershell
cd C:\Users\tadaaaki\.gemini\antigravity\scratch\sales-ledger-sheet
git branch -M main
git remote add origin https://github.com/tadaaki-hub/sales-ledger-sheet.git
git push -u origin main
```

### ステップ2：社員や税理士さんをリポジトリに招待する

1. GitHubのリポジトリページを開き、上部メニューの **`Settings`** &gt; 左メニューの **`Collaborators`** を開きます。
2. **`Add people`** ボタンを押し、共有したい社員や税理士さんのGitHubアカウント（またはメールアドレス）を入力して招待します。
   - **社員（売上・入金を入力する方）**：`Write` 権限
   - **税理士さん（閲覧・CSVダウンロードのみの方）**：`Read` 権限

### ステップ3：ブラウザ画面から「⚙ 共有設定」を行う

1. GitHub右上のプロフィールアイコン &gt; **`Settings`** &gt; 左下 **`Developer settings`** &gt; **`Personal access tokens`** &gt; **`Fine-grained tokens`** を開きます。
2. **`Generate new token`** を押し、以下のように設定してトークンを発行します：
   - **Repository access**: `Only select repositories` ➔ `sales-ledger-sheet` を選択
   - **Permissions (Repository permissions)**: **`Contents`** を **`Read and write`**（閲覧専用の税理士さんは `Read-only`）に設定
3. このアプリ（`index.html`）を開き、画面右上の **「⚙ 共有設定」** ボタンをクリックします。
4. **オーナー名**（例：`tadaaki-hub`）、**リポジトリ名**（例：`sales-ledger-sheet`）、発行した **Personal Access Token** を入力して **「🔌 接続テスト」** ➔ **「✓ 設定を保存して閉じる」** を押します。
   - ※入力したトークンはお使いのPCブラウザ内（`localStorage`）にのみ保存され、GitHub上のファイルには一切書き込まれないため安全です。

## 💡 日常の運用フロー

- **作業を始める時**：アプリを開くと自動でGitHub上の最新 `data.json` が読み込まれます（手動で **「☁ 最新を取得 (Pull)」** を押すこともできます）。
- **売上・入金を入力した時**：セルに入力したあと、画面上部の **「⬆ GitHubへ保存 (Push)」** ボタンを押すと、GitHub上の `data.json` が更新され、他の社員や税理士さんの画面にも最新データが共有されます。
- **変更履歴（バックアップ）**：GitHubのコミット履歴（History）に「いつ・誰が・どの売上データを更新したか」がすべて自動記録されるため、誤って消してしまった場合でもいつでも過去の状態に戻せます。
